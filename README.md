# 🌐 Personal Portfolio Website

A modern and responsive personal portfolio website built using HTML, CSS, and JavaScript.

## ✨ Features

- Responsive Design
- Dark / Light Mode
- Smooth Scrolling
- Animated Sections
- Skills Section
- Projects Section
- Contact Form
- Resume Download Button

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## 📂 Project Structure

```
portfolio/
│── index.html
│── style.css
│── script.js
│── images/
│── resume.pdf
```

## 🚀 How to Run

1. Download or Clone the Repository.
2. Open the project in VS Code.
3. Install the Live Server extension.
4. Open `index.html`.
5. Click **Go Live**.
